# Quiz de multiplicação

Aplicativo Flutter para praticar multiplicação com fatores de 1 a 10.

Cada rodada apresenta 10 perguntas aleatórias, com quatro alternativas e
feedback em SnackBar. Ao final, o aplicativo mostra a pontuação e permite jogar
novamente.

Para executar, use `flutter run` na pasta do projeto. Para validar, use
`flutter test`.
